## 4. 指标口径

## 4.1 外包时点在职人数

### 业务定义

**外包时点在职人数 = 当前筛选时间范围内“最新可用业务日期”的外包在职人数。**

其中“时点”的含义即：**取最新一天。**

### 计算逻辑

1. 根据当前筛选时间范围确定 `AsOfDate`；
2. `AsOfDate = MAX(stat_pt)`；
3. 仅取 `stat_pt = AsOfDate` 的记录；
4. 汇总 `onjob_stf_emp_cnt_d`。

逻辑表达：

```text
AsOfDate = 当前筛选范围内 MAX(stat_pt)

外包时点在职人数
= SUM(onjob_stf_emp_cnt_d)
  WHERE stat_pt = AsOfDate
```

### 时间场景

| 场景 | 取数方式 |
|---|---|
| 当前自然月 | 取当前月最新已刷新业务日期 |
| 历史月份 | 取该月最后一个可用业务日期 |
| YTD / 多月份 | 取整个筛选范围最后一个可用业务日期 |
| 未来月份 | 按驾驶舱全局数据可用性规则隐藏/显示“—” |

> 不要求自然日必须连续；“最新一天”以底表实际存在的 `stat_pt` 为准。

---

## 4.2 外包日均在职人数

### 业务定义

**外包日均在职人数 = 所选期间每日外包在职人数的平均值。**

技术中台已确认可按以下逻辑加工：

```text
SUM(当天_在职_外包员工数)
÷ COUNT(DISTINCT 数据日期)
```

对应 Nexus 字段：

```text
外包日均在职人数
= SUM(onjob_stf_emp_cnt_d)
  / COUNT(DISTINCT stat_pt)
```

### 重要规则

- 分母是**实际存在数据的不同业务日期数**，不是明细行数；
- 不允许使用 `COUNT(*)` 作为分母；
- 当前自然月计算至最新已刷新日期；
- 历史月份按该月全部可用日期计算；
- YTD / 多月份按整个筛选范围内全部可用日期计算；
- 计算保留原始精度，KPI 页面最终按 Demo 展示为整数“人”。

---

## 4.3 外包入职人数（支持Measure）

### 业务定义

**外包入职人数 = 所选期间外包员工入职人数累计。**

建议统一使用日字段累计：

```text
STF_外包入职人数
= SUM(entry_stf_emp_cnt_d)
```

这样同一 Measure 可以同时支持单月、YTD及任意连续时间范围。

`entry_stf_emp_cnt_mtd` 仅用于单月验数，不作为跨日期直接求和字段。

---

## 4.4 外包离职人数（支持Measure）

### 业务定义

**外包离职人数 = 所选期间外包员工离职人数累计。**

建议：

```text
STF_外包离职人数
= SUM(termination_stf_emp_cnt_d)
```

`termination_stf_emp_cnt_mtd` 仅用于单月验数，不允许跨日期直接 SUM。

---

## 4.5 外包净增人数

### 已确认业务口径

**外包净增人数 = 外包入职人数 − 外包离职人数。**

即：

```text
STF_外包净增人数
= STF_外包入职人数
- STF_外包离职人数
```

等价底表逻辑：

```text
SUM(entry_stf_emp_cnt_d)
- SUM(termination_stf_emp_cnt_d)
```

### 特别说明

**净增人数不使用“期末在职 − 期初在职”作为正式计算公式。**

原因：人员状态修正、历史补录、口径调整等情况可能导致：

```text
期末在职 - 期初在职 ≠ 入职人数 - 离职人数
```

因此：

- “外包净增人数”以**入职 − 离职**为准；
- 不将“期初 + 净增 = 期末”作为正式口径或强制验收条件。

## 5. KPI 卡片展示要求

STF 业务线指标区域展示三张卡片：

1. 外包时点在职人数
2. 外包日均在职人数
3. 外包净增人数

### 5.1 页面格式

示例：

```text
外包时点在职人数
1,206 人
同比 -1.2%（-15）
环比 -2.6%（-32）
```

### 5.2 展示规则

| 项目 | 要求 |
|---|---|
| 单位 | 人 |
| UNIT筛选器 | 不参与元/千元/万元换算 |
| 主值 | 显示整数 |
| 同比 | 同比百分比 + 同比绝对差 |
| 环比 | 环比百分比 + 环比绝对差 |
| 正负样式 | 沿用驾驶舱 Demo 样式 |
| More | 本版暂不开发；待业务方确认展示方案后另行补充 |

同比/环比绝对差：

```text
同比差额 = 本期值 - 同期值
环比差额 = 本期值 - 上期值
```

同比/环比百分比：

```text
同比% = (本期值 - 同期值) / 同期值
环比% = (本期值 - 上期值) / 上期值
```

如果同期值或上期值 = 0：

- 百分比显示 `—`；
- 绝对差仍正常展示。

## 6. 同比 / 环比时间对齐规则

三个指标必须使用**同口径时间截止点**进行比较，不能用“当前月截至10日”直接对比“上月完整月”。

### 6.1 单月场景

假设当前选中 2026-09，底表最新可用日期为 2026-09-10：

| 比较 | 时间范围 / 时点 |
|---|---|
| 本期 | 2026-09-01 ～ 2026-09-10 |
| 同期 | 2025-09-01 ～ 2025-09-10 |
| 上期 | 2026-08-01 ～ 2026-08-10 |

其中：

- **时点在职人数**：分别取 2026-09-10、2025-09-10、2026-08-10 的时点值；
- **日均在职人数**：分别计算三个同长度期间日均；
- **净增人数**：分别累计三个同长度期间的入职 − 离职。

如果本期为完整历史月，则同期、上期也按完整月份比较。

### 6.2 月末特殊规则

若本期最新业务日期为该月最后可用日 / 月末：

- 环比使用上月最后可用日 / 月末；
- 同比使用上年同月最后可用日 / 月末。

### 6.3 日期缺失

若目标同比/环比日期无数据：

- 在目标月份内向前寻找最近一个可用 `stat_pt`；
- 不允许因为缺一天数据而直接取下一自然月日期。

### 6.4 YTD / 多月份场景

- 本期指标按实际选择的完整日期范围计算；
- 同比使用上一年度对应日期范围；
- **YTD / 多月份“环比”如主驾驶舱已有统一定义，则直接继承；如主规则尚未明确，不在本需求内自行创造新口径，页面环比先显示“—”。**

## 9. MTD 字段使用约束

底表包含：

```text
entry_stf_emp_cnt_mtd
termination_stf_emp_cnt_mtd
```

以上字段为**月累计值**。

### 禁止

```text
跨多个 stat_pt 直接 SUM(entry_stf_emp_cnt_mtd)
跨多个 stat_pt 直接 SUM(termination_stf_emp_cnt_mtd)
```

因为会重复累计。

### 可用于

单月验数时，在该月 `AsOfDate`：

```text
SUM(entry_stf_emp_cnt_mtd)
应与
该月截至 AsOfDate 的 SUM(entry_stf_emp_cnt_d)
基本一致
```

离职同理。

正式指标建议统一基于日字段计算，以支持单月、YTD和多月份场景。

## 10. 数据刷新及可用性

开发需要读取 Nexus 中完整历史分区，并根据 `stat_pt` 自动识别最新可用日期。

不得：

- 在代码中写死“昨天”；
- 在代码中写死某个固定日期；
- 根据 Excel 文件名判断最新数据日期。

应使用：

```text
MAX(stat_pt)
```

结合驾驶舱全局数据可用性规则确定 `AsOfDate`。

如果源表当天尚未刷新，指标继续使用最新已存在的 `stat_pt`，不得显示 0 冒充最新值。

## 11. 验收标准

开发完成后至少按以下规则验收。

### 11.1 数据源

- [ ] 指标读取 Nexus 正式表 `ads_biz_oper_stf_emp_pos_hire_ter_cnt_stats_1d`；

- [ ] 组织筛选使用 `fin_bu_new / fin_team_new / fin_sub_team_new`。

### 11.2 外包时点在职人数

- [ ] 只取当前范围最新一个 `stat_pt`；
- [ ] 值 = 当天 `SUM(onjob_stf_emp_cnt_d)`；
- [ ] 当前月随底表最新日期更新；
- [ ] 历史月取当月最后可用日期。

### 11.3 外包日均在职人数

- [ ] 值 = `SUM(onjob_stf_emp_cnt_d) / COUNT(DISTINCT stat_pt)`；
- [ ] 分母不是明细行数；
- [ ] 当前月只平均至最新可用日期。

### 11.4 外包净增人数

- [ ] 值 = `SUM(entry_stf_emp_cnt_d) - SUM(termination_stf_emp_cnt_d)`；
- [ ] 不使用期末在职 − 期初在职作为正式公式；
- [ ] MTD 字段没有跨日期重复求和。

### 11.5 同比 / 环比

- [ ] 当前非完整月与同期/上期采用相同截止日；
- [ ] 同比、环比同时展示百分比与绝对差；
- [ ] 比较基数 = 0 时比例显示“—”；
- [ ] 历史完整月按完整月比较。

## 13. 开发原则总结

本需求的核心实现逻辑为：

```text
底表（日粒度）
   ↓
建立可复用原子 Measure
   ↓
外包时点在职：取最新日
外包日均在职：日值求期间平均
外包净增：入职累计 - 离职累计
   ↓
统一时间框架计算同比 / 环比
```

**不要通过复制 Demo 模拟数字实现指标，也不要通过“期末 - 期初”替代已确认的净增业务口径。More 待业务方确认后再开发。**
