## 1. 数据源与组织维度

数仓分别加工三张事实表：

1. 应收事实表：`fis_analysis_dm.app_fis_ar_receipt_status`
2. 到账事实表：`fis_analysis_dm.app_fis_ar_check_detail_fund`
3. 已发薪未开票事实表：`ato_dm.app_biz_oper_stf_salarynotice_invoice_statistics`

三张表共用/补齐以下分析维度：

- 同比映射后 BU
- 同比映射后 Team
- 同比映射后 Subteam
- BU_Head / Team_Head / Subteam_Head / Squad_Head
- 客户集团
- 业务线
- 发票抬头
- 资金组用 BU Head / Team Head（如资金专项页使用）

三张事实表**不直接逐行关联**。同一筛选器分别下推至对应事实表，再在指标层汇总。

## 2. 快照与时间规则

### 2.1 当前自然月

- 当月保留每日全量快照；
- Nexus 默认使用最新可用快照；
- 页头展示：`数据截至 YYYY-MM-DD`；
- 每次指标查询限定一个快照日期，防止多快照重复累加。

### 2.2 历史月份

- 历史月份每月只保留一张冻结快照；
- 冻结日期**不得用自然月末推导**；
- 必须读取 FIS：`基础设置 → 每月收款核销截止时间设置`；
- 该截止时间对应的快照作为会计期间历史冻结值，后续不重新推送、不随当前数据变化。

### 2.3 数据时效

快照日期 D 的数据代表 D 日约 23:00 补核销后的完整状态；若生产表的实际刷新时间由数据团队另有定义，以数据团队最终确认的刷新字段为准。

## 3. 驾驶舱一期直接使用的 Measure

### 3.1 R08-1｜逾期金额

业务口径：

```text
逾期金额
= SUM(应收事实表[未收金额])
WHERE 应收事实表[逾期状态] = "已逾期"
  AND 快照日期 = 当前选定快照
```

说明：

- 驾驶舱展示名：**逾期金额**
- 来源：应收事实表
- 不跨快照累加
- 组织/客户筛选使用数仓输出的标准维度字段

### 3.2 R08-2｜未开票金额

业务口径：

```text
未开票金额
= SUM(已发薪未开票事实表[通知单员工总额])
WHERE 已发薪未开票事实表[是否逾期开票] = "是"
  AND 快照日期 = 当前选定快照
```

说明：

- 驾驶舱展示名：**未开票金额**
- 含未关联部分
- 来源：已发薪未开票事实表
- 不跨快照累加

### 3.3 R08｜逾期 & 未开票金额

```text
逾期 & 未开票金额
= [逾期金额] + [未开票金额]
```

- 两个 Measure 在当前统一筛选上下文下相加；
- 不拼接两张明细事实表；
- 总看板使用组合指标；STF 页面可拆分为两个独立卡片。

## 4. 支持 Measure / 资金专项页可复用指标

以下指标可为专项页或后续驾驶舱复用，开发时建议一并按原子 Measure 管理：

| 指标 | 来源 | 口径 |
| --- | --- | --- |
| 应收金额 | 应收事实表 | `未收金额`，按已确认业务条件过滤 |
| 逾期金额占比 | 应收事实表 | 客户集团逾期金额 ÷ 当前筛选上下文逾期金额总计；仅移除表格当前客户集团行上下文，保留页面筛选 |
| 平均逾期天数 | 应收事实表 | `AVERAGE(逾期天数)`，限定有效逾期记录 |
| 平均账期 | 应收事实表 | `AVERAGE(付款期限)` |
| 超期未开票金额占比 | 已发薪未开票事实表 | 客户集团超期未开票金额 ÷ 当前筛选上下文超期未开票金额总计；仅移除表格当前客户集团行上下文，保留页面筛选 |
| 超期天数 | 已发薪未开票事实表 | 使用数仓加工的超期天数，限定 `是否逾期开票=是` |
| 到账金额 | 到账事实表 | `SUM(核销金额)`；如展示“当月到账”，增加 `核销日期属于当前月` |
| 开票金额 | 组合 | 到账金额 + 应收金额（仅在明确业务场景使用） |

> `未回款账期期数` 一期不开发。

## 5. R20｜资金明细页

两张明细独立展示，不做逐行拼接。

### 5.1 逾期应收明细

按 `客户集团 → 预计收款月份` 展开，至少展示：

- 截至目前应收
- 逾期金额
- 逾期金额占比
- 平均逾期天数
- 平均账期
- 表格底部总计

### 5.2 超期未开票明细

按 `客户集团 → 发薪月份` 展开，至少展示：

- 超期未开票金额
- 超期未开票金额占比
- 平均超期天数
- 表格底部总计

### 5.3 占比与总计规则

占比按客户集团汇总行计算：

```text
逾期金额占比
= 当前客户集团逾期金额 / 当前筛选上下文逾期金额总计

超期未开票金额占比
= 当前客户集团超期未开票金额 / 当前筛选上下文超期未开票金额总计
```

- “当前筛选上下文”包含业务线、组织、四级负责人、客户集团筛选器、当前快照及 RLS；计算分母时只移除表格客户集团汇总行带来的行上下文，不得移除页面筛选器上下文；
- 当客户集团筛选器仅选中一个集团时，该集团占比为 `100.00%`；
- 占比保留两位小数；各集团占比合计允许因四舍五入产生微小尾差；
- 分母为 0 时占比展示 `—`，不得展示无穷大或 `NaN`；
- 占比仅展示在客户集团汇总行；展开后的预计收款月份/发薪月份行展示 `—`；
- 两张明细表底部均展示“总计”行并随当前筛选联动：金额字段求和，占比在金额总计非 0 时展示 `100.00%`，平均类字段按当前表内有效明细记录重新计算，不对集团平均值做简单平均；
- 逾期应收总计展示：截至目前应收、逾期金额、逾期金额占比、平均逾期天数、平均账期；
- 超期未开票总计展示：超期未开票金额、超期未开票金额占比、平均超期天数。

### 5.4 排序与展开规则

- 逾期应收集团层默认按“逾期金额”从大到小排序；逾期金额相同时，依次按“截至目前应收”从大到小、客户集团名称升序排序；
- 超期未开票集团层默认按“超期未开票金额”从大到小排序；金额相同时按客户集团名称升序排序；
- 逾期应收展开层按预计收款月份汇总：先展示逾期金额大于 0 的月份，再展示逾期金额为 0 但截至目前应收不为 0 的月份；两类内部均按 `YYYY-MM` 从近到远排序；
- 逾期应收展开层中，截至目前应收与逾期金额按页面展示精度取整后均为 0 的月份不展示；
- 超期未开票展开层仅展示按页面展示精度取整后金额不为 0 的月份，并按发薪月份 `YYYY-MM` 从近到远排序；
- 无法识别为标准 `YYYY-MM` 的“未匹配月份”始终置于对应展开明细末尾；
- 排序在当前页面筛选、快照及 RLS 上下文生效后执行，不改变总计口径；
- 展开月份必须渲染为父表中的直接子行，与集团行共用同一组列和列宽；不得使用独立计算列宽的嵌套表格，避免表头、集团行和月份行错列。

### 5.5 筛选与权限

继承驾驶舱当前有效的：

- 业务线
- BU / Team / Subteam
- 四级负责人
- 客户集团
- 当前快照
- RLS

## 6. 与主驾驶舱时间轴的关系

资金指标属于**快照型余额**，不能按 Rev/NFI 的月度流量逻辑处理。

- 当前月：展示最新每日快照；
- 历史月：展示该会计期间 FIS 配置的冻结快照；
- YTD：取 YTD 结束月份对应快照，**不把各月逾期余额相加**；
- 趋势月度点：每月一个对应快照；
- 季度趋势：取季度结束月份对应快照，不对季度三个月余额求和。

## 7. 开发约束

1. 正式开发读取 Nexus / 数仓正式表，不读取 HTML 内嵌样例数据；
2. 不允许将同一客户在三张事实表之间做不必要的逐行关联；
3. 每次查询必须有明确的单一快照上下文；
4. 同名维度优先使用数仓标准输出列；
5. 空值不得被前端转换为 0；
6. 页面必须能说明数据截至日期；
7. 历史数据必须可追溯到对应会计期间的 FIS 冻结快照。

## 8. 验收标准

- [ ] R08-1 在选定快照下与应收事实表验数一致；
- [ ] R08-2 在选定快照下与未开票事实表验数一致；
- [ ] R08 = R08-1 + R08-2；
- [ ] 同一快照不会因底表多日期重复累计；
- [ ] 当前月切换最新快照后指标同步更新；
- [ ] 历史月份按 FIS 配置日期冻结，后续不漂移；
- [ ] YTD/季度不会把余额型指标跨月求和；
- [ ] 组织/客户筛选能分别下推到对应事实表；
- [ ] RLS 与主驾驶舱一致；
- [ ] More/专项页明细与卡片在同一快照和筛选上下文下可解释；
- [ ] 逾期应收与超期未开票明细均展示随筛选联动的总计行；
- [ ] 两张明细按客户集团展示金额占比，占比以各自当前筛选总额为分母并保留两位小数；
- [ ] 客户集团筛选为单一集团时占比为 `100.00%`，分母为 0 时展示 `—`；
- [ ] 总计行的平均类字段基于当前有效明细重新计算，不对集团平均值做简单平均；
- [ ] 逾期应收集团按逾期金额降序、超期未开票集团按超期未开票金额降序，金额相同时按规定的次级字段稳定排序；
- [ ] 展开明细按预计收款月份/发薪月份从近到远排序，“未匹配月份”置底；
- [ ] 逾期应收展开明细优先展示有逾期金额的月份，按页面展示精度取整后的双零月份不展示；
- [ ] 展开月份行与集团行、表头共用列宽，展开和收起时均不得出现错列。
